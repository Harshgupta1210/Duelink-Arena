# **App Name**: Duelink Arena

## Core Features:

- Classmate List & Invite: Display a list of classmates with online status and invite functionality. Includes search and filter options.
- Realtime 1v1 Challenge Room: Implement a real-time challenge room with a countdown timer, question display, live scoring, and chat functionality.
- Match Result Persistence: Store and display match results, including question snapshots and share functionality. Access previous game match information from firestore database.
- Leaderboard: Generate leaderboards per section/class with filters for different periods (daily/weekly/all-time).
- Invitation Handling: Manage pending invites (sent/received) with accept/reject functionality.
- User Authentication: Allow user to login into system with existing credentials.

## Style Guidelines:

- Primary color: Saturated blue (#29ABE2) to convey intelligence, skill, and trust.
- Background color: Light, desaturated blue (#E5F5FB) to provide a clean and modern backdrop.
- Accent color: Analogous blue-green (#29E2A7) to provide interactive visual cues, call to actions, and important notifications
- Font for headings and body text: 'Space Grotesk', a proportional sans-serif, lending a techy, scientific feel that enhances the game's atmosphere.
- Use sharp, minimalist icons to represent classmates, status, and leaderboard positions.
- Mobile-first responsive layout with stacked elements in the challenge room for smaller screens.
- Subtle transitions and animations for score updates and timer countdowns to enhance user engagement.
